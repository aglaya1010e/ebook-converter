# Ebook Tools

Элегантный конвертер и разделитель электронных книг с приватной обработкой файлов прямо в браузере.

## Возможности

- **Конвертер**: Преобразование EPUB, MOBI и FB2 в TXT
- **Разделитель**: Разделение TXT файлов на 1-10 частей

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173` в браузере.

## Развертывание

Подробные инструкции по установке, запуску и публикации на GitHub Pages находятся в файле **INSTRUCTIONS.md**

## Приватность

Все файлы обрабатываются локально. Ваши данные никогда не покидают браузер.

## Технологии

- Vite
- JSZip
- DOMParser
- FileReader API
