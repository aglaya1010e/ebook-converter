# Ebook to TXT - Quiet Luxury Converter

Элегантный и приватный конвертер электронных книг, работающий полностью в браузере.

## Как запустить проект локально

Для запуска вам понадобятся установленные [Node.js](https://nodejs.org/) и npm.

### 1. Перейдите в папку проекта
Откройте терминал или PowerShell и перейдите в директорию проекта:
```powershell
cd C:\Users\user\.gemini\antigravity\scratch\ebook-converter
```

### 2. Установите зависимости
Выполните команду для установки необходимых библиотек (JSZip и Vite):
```powershell
npm install
```

### 3. Запустите сервер разработки
После установки зависимостей запустите локальный сервер:
```powershell
npm run dev
```

### 4. Откройте приложение
В терминале появится ссылка (обычно `http://localhost:5173`). Нажмите на неё или скопируйте в адресную строку браузера.

## Публикация на GitHub Pages

Эта инструкция поможет вам опубликовать конвертер, чтобы им можно было пользоваться онлайн без установки.

### Подготовка: Что вам понадобится

1. **Аккаунт на GitHub** — зарегистрируйтесь на [github.com](https://github.com), если еще не сделали этого
2. **Git** — установите Git с официального сайта [git-scm.com](https://git-scm.com/downloads)
   - После установки перезапустите терминал/PowerShell
   - Проверьте установку командой: `git --version`

### Шаг 1: Создание репозитория на GitHub

1. Зайдите на [GitHub](https://github.com) и войдите в свой аккаунт
2. Нажмите на кнопку **"+"** в правом верхнем углу и выберите **"New repository"**
3. Заполните форму:
   - **Repository name**: например, `ebook-converter` (можно любое название на латинице)
   - **Description**: краткое описание (например, "Конвертер электронных книг")
   - Выберите **Public** (публичный репозиторий)
   - **Не ставьте галочки** на "Add a README file", "Add .gitignore" и "Choose a license"
4. Нажмите **"Create repository"**
5. **Скопируйте URL репозитория** — он будет вида `https://github.com/ваш-username/ebook-converter.git`

### Шаг 2: Настройка конфигурации Vite

Vite нужно знать, по какому пути будет доступно ваше приложение на GitHub Pages.

1. Откройте файл `vite.config.js` в корне проекта (если его нет, создайте)
2. Вставьте следующий код (замените `ebook-converter` на название вашего репозитория):

```javascript
export default {
  base: '/ebook-converter/'
}
```

**Важно**: название должно точно совпадать с названием репозитория!

3. Сохраните файл

### Шаг 3: Настройка Git (первый раз)

Если вы используете Git впервые, настройте свои данные:

```powershell
git config --global user.name "Ваше Имя"
git config --global user.email "ваш-email@example.com"
```

Используйте тот же email, что и на GitHub.

### Шаг 4: Сборка проекта

Соберите production-версию проекта:

```powershell
cd C:\Users\user\.gemini\antigravity\scratch\ebook-converter
npm run build
```

После выполнения команды появится папка `dist` с готовыми файлами для публикации.

### Шаг 5: Публикация (простой способ через gh-pages)

Это самый простой способ для новичков.

#### 5.1. Установка пакета gh-pages

```powershell
npm install --save-dev gh-pages
```

#### 5.2. Добавление скрипта деплоя

1. Откройте файл `package.json`
2. Найдите раздел `"scripts"` (обычно в начале файла)
3. Добавьте строку с командой `deploy` (не забудьте запятую после предыдущей строки):

```json
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview",
  "deploy": "gh-pages -d dist"
},
```

4. Сохраните файл

#### 5.3. Инициализация Git и связывание с GitHub

1. Инициализируйте Git-репозиторий в папке проекта:
   ```powershell
   git init
   ```

2. Добавьте все файлы проекта:
   ```powershell
   git add .
   ```

3. Создайте первый коммит:
   ```powershell
   git commit -m "Первая версия конвертера"
   ```

4. Переименуйте ветку в `main` (современный стандарт):
   ```powershell
   git branch -M main
   ```

5. Свяжите локальный репозиторий с GitHub (замените URL на ваш):
   ```powershell
   git remote add origin https://github.com/ваш-username/ebook-converter.git
   ```

6. Загрузите код на GitHub:
   ```powershell
   git push -u origin main
   ```

   **Если попросит авторизацию**: введите свой логин и пароль от GitHub (или Personal Access Token)

#### 5.4. Деплой на GitHub Pages

Теперь просто выполните:

```powershell
npm run deploy
```

Эта команда автоматически:
- Возьмет содержимое папки `dist`
- Создаст ветку `gh-pages`
- Загрузит файлы на GitHub

### Шаг 6: Активация GitHub Pages (в настройках репозитория)

1. Зайдите в свой репозиторий на GitHub (например, `https://github.com/ваш-username/ebook-converter`)
2. Нажмите на вкладку **Settings** (настройки) в верхнем меню
3. В левом боковом меню найдите и нажмите **Pages**
4. В разделе **Branch** (ветка):
   - Выберите ветку: `gh-pages`
   - Папка: `/ (root)`
5. Нажмите **Save**

### Шаг 7: Готово! 🎉

Подождите 1-2 минуты, и ваше приложение будет доступно по адресу:

```
https://ваш-username.github.io/ebook-converter/
```

Если страница не открывается сразу, подождите еще немного — GitHub Pages может занять до 5 минут на первый деплой.

## Возможные проблемы и решения

### Проблема: "git: command not found"
**Решение**: Git не установлен. Скачайте и установите с [git-scm.com](https://git-scm.com/downloads), затем перезапустите терминал.

### Проблема: "Permission denied" при git push
**Решение**: 
1. Убедитесь, что вы вошли в GitHub
2. Для Windows рекомендуется использовать Personal Access Token вместо пароля:
   - Зайдите в Settings → Developer settings → Personal access tokens → Tokens (classic)
   - Нажмите "Generate new token"
   - Выберите срок действия и права (минимум `repo`)
   - Используйте этот токен вместо пароля

### Проблема: Сайт показывает 404
**Решение**:
1. Проверьте, что в `vite.config.js` указано правильное название репозитория
2. Пересоберите проект: `npm run build`
3. Повторите деплой: `npm run deploy`
4. Подождите 5 минут

### Проблема: Стили не загружаются (белая страница)
**Решение**: Скорее всего, неправильно настроен `base` в `vite.config.js`. Проверьте, что название совпадает с названием репозитория.

## Безопасность и Приватность
Приложение не имеет серверной части. Все файлы парсятся прямо в браузере клиента с использованием `FileReader API`, `JSZip` и `DOMParser`. Ваши книги не сохраняются и не передаются ни в какое облако.
